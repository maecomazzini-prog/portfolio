# Kardz Product Design Case

HTML/CSS case preparado para GitHub Pages.

## Assets
Substitua os arquivos em `assets/` mantendo os nomes:
- hero.svg
- feed.svg
- card-detail.svg
- seller.svg
- register.svg

Pode trocar SVG por JPG/PNG alterando as referências no `index.html`.

## GitHub Pages
Suba o conteúdo do diretório para um repositório e ative Settings → Pages → Deploy from branch → main → root.

O botão Print / PDF usa a impressão nativa do navegador.
